# RescueMesh AI — Rescue Team Web Dashboard

The live React + TypeScript + Tailwind CSS + Leaflet + Socket.IO Rescue Team Command Dashboard is served directly by the root full-stack application (`src/components/dashboard/RescueDashboard.tsx` and `src/components/map/VictimLeafletMap.tsx`).

Run `npm run dev` from the repository root to start the live dashboard and backend API on `http://localhost:3000`.
